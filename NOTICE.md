## Modifications
The following modifications have been made to the original codebase to support managed hosting services:
- Introduction of dynamic user plans (free, basic, pro, white_label) with distinct alert limits.
- Addition of administrative commands for client management (`/admin_setplan`).
- Addition of client commands (`/myplan`, `/setchannel`, `/testchannel`).
- Addition of mandatory financial disclaimers to comply with regulatory standards.
- Implementation of Docker Compose for robust 24/7 VPS deployment.
- Enhanced error handling for Telegram group/channel permission issues.
